How It Works

Each key is generated using HMAC-SHA256 with a secret salt. The key format:

OPENRX-{tier}{timestamp}-{expiry}{checksum}-{checksum}
  • tier: B=Basic, P=Professional, E=Enterprise
  • timestamp: Encoded generation time (hex)
  • expiry: Encoded duration in months (hex)
  • checksum: HMAC-SHA256 truncated to 4 hex chars

Keys work offline — no internet required for validation.
